## 📦 包含什么

### 1. 市场简报生成器
自动生成每日市场简报，含**趋势系数**排名：

```bash
node demo_report.js
```

输出示例：
```
强势币 TOP5: ZEC(80) / UNI(80) / ARB(80) / OP(79) / BCH(70)
弱势币 TOP5: XRP(-15) / ATOM(-14) / TRX(-13) / BTC(-9) / ETH(-6)
```

**趋势系数** = 长期趋势(±25) + 短期趋势(±15) + 7日动量(±20) + 24h动量(±20)

### 2. 仓位风控守护
监控持仓，到止损位**反复提醒**（不是提醒一次就完事）：

```bash
node position_guard.js
```

### 3. 移动止损守护
按 ATR 计算动态止损，随价格移动：

```bash
node trailing_guard.js
```

### 4. 庄家痕迹识别
从K线识别可能的控盘迹象：
- 长下影护盘（跌下去立即被买回）
- 缩量上涨（少量资金控盘）
- 暴量拉升（逼空）

```bash
node whale_tracker.js
```

## 🚀 快速开始

```bash
# 1. 安装
npm install ccxt https-proxy-agent dotenv

# 2. 配置（复制 .env.example）
cp .env.example .env
# 编辑 .env 填入你的币安API（只读权限即可）

# 3. 运行
node demo_report.js        # 市场简报
node position_guard.js     # 持仓监控（需配置TG推送）
```
