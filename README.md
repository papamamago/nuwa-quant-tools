> 加密量化交易的实用工具 | 诚实、可用、无套路

一套自用的加密量化交易工具，开源出来：

- 只提供**能跑的工具**和**诚实的验证数据**

## 包含什么

### 1. 市场简报生成器 (`demo_report.js`)
自动生成每日市场简报：
- 趋势系数排名（强势/弱势币）
- 风险提示（高波动/缩量币）
- 8维数据摘要

```bash
node demos/demo_report.js
```

### 2. 仓位风控守护 (`position_guard.js`)
监控持仓，到止损位反复提醒：
- 每2分钟检查
- 距止损越近提醒越频繁
- 多通道推送（重试3次）

### 3. 移动止损守护 (`trailing_guard.js`)
按ATR计算动态止损：
- 随价格移动
- 回撤超过阈值提醒

### 4. 庄家痕迹识别 (`whale_tracker.js`)
识别可能的控盘迹象：
- 长下影护盘
- 缩量上涨
- 暴量拉升（逼空）
